# Approval Workflow

1. **Define:** State objective, scope, deliverables, boundaries, and any external or financial actions.
2. **Review:** Identify evidence, assumptions, risks, conflicts, and affected documents.
3. **Approve:** Obtain explicit founder approval for the proposed phase or consequential action. Approval is limited to the stated scope.
4. **Execute:** Work only within approved limits. Pause if a destructive conflict, new cost, external commitment, or material scope change arises.
5. **Validate:** Check outputs against stated acceptance criteria and report failures or uncertainty honestly.
6. **Record:** Update decisions, risks, assumptions, and changes when material.

Drafts and recommendations are not approval. No external account, transaction, publication, contract, or deployment is authorized by this workflow alone.
