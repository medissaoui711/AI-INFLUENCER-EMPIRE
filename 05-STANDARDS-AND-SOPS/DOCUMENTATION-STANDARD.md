# Documentation Standard

- Use English, Markdown, descriptive uppercase filenames, and hyphens for core company documents.
- Start each document with one H1 title; use headings in order and concise tables where they clarify ownership or status.
- Use ISO dates (`YYYY-MM-DD`). If a historical date is unknown, write “Not recorded”.
- Label information as approved decision, verified fact, hypothesis, unknown, or recommendation where ambiguity is possible.
- Cite the evidence source for material claims; avoid invented metrics, names, roles, or status.
- Assign an owner and review when the document affects decisions, controls, external claims, or execution.
- Keep sensitive personal data and credentials out of the repository.
- Record material approved changes in the relevant register and changelog.
